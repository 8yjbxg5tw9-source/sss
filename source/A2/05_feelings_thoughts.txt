## Feelings and thoughts | Hisslər və düşüncələr
@ FEEL | verb | fiːl | hiss etmək, duymaq; özünü ... hiss etmək
forms: feel – feels – felt – felt – feeling
n: feeling = hiss, duyğu
- feel sick = ürəyi bulanmaq; özünü xəstə hiss etmək :: Britaniyada əsasən: ürəkbulanma
- feel hungry = aclıq hiss etmək, acmaq :: hungry = ac
- feel thirsty = susamaq :: thirsty = susuz
- feel sorry = təəssüflənmək, heyfsilənmək :: feel sorry for + kim = kiməsə yazığı gəlmək
- feel lonely = özünü tənha hiss etmək :: lonely = tənha, kimsəsiz
- feel nervous = həyəcanlanmaq, narahat olmaq :: nervous = həyəcanlı ("əsəbi" deyil!)
- feel comfortable = özünü rahat hiss etmək :: comfortable = rahat
- feel like = istəmək, könlü çəkmək :: feel like + isim / fel + -ing
> I feel sick. I need some fresh air. = Ürəyim bulanır. Mənə təmiz hava lazımdır.
> I always feel nervous before exams. = Mən imtahanlardan əvvəl həmişə həyəcanlanıram.
> She felt lonely in the new city. = O, yeni şəhərdə özünü tənha hiss edirdi.
> I feel like going for a walk. = Gəzməyə getmək istəyirəm.
! FEEL düzgün olmayan feldir: feel – felt – felt. FEEL-dən sonra zərf yox, sifət gəlir: I feel good / tired / nervous. Azərbaycan dilindən fərqli olaraq, qayıdış əvəzliyi lazım deyil: "I feel well" ("I feel myself well" səhvdir). NERVOUS "həyəcanlı, narahat" deməkdir; "əsəbi, hirsli" üçün "angry" işlənir. "Feel like + -ing" danışıqda istək bildirir.

@ THINK | verb | θɪŋk | düşünmək, fikirləşmək; zənn etmək
forms: think – thinks – thought – thought – thinking
n: thought = fikir, düşüncə; thinker = mütəfəkkir; thinking = düşünmə, düşüncə tərzi
adj: thoughtful = diqqətcil, qayğıkeş, həmçinin fikirli
- think about = barəsində düşünmək, götür-qoy etmək :: think about + isim / fel + -ing
- think of = ağlına gətirmək; haqqında fikirdə olmaq :: What do you think of ...? = ... haqqında nə düşünürsən?
- think twice = yaxşı-yaxşı düşünmək, ölçüb-biçmək :: twice = iki dəfə
- think positive = müsbət düşünmək :: positive = müsbət; danışıq ifadəsi
- think it over = götür-qoy etmək, ətraflı düşünmək :: Frazeoloji fel; qərardan əvvəl
- I think so = məncə, elədir; deyəsən, hə :: İnkarı: I don't think so
- think deeply = dərindən düşünmək :: deep (dərin) + -ly
- on second thoughts = bir də fikirləşəndə (fikrimi dəyişdim) :: Britaniya idiomu
> What are you thinking about? = Nə barədə düşünürsən?
> What do you think of my new haircut? = Yeni saç düzümüm haqqında nə düşünürsən?
> Think twice before you answer. = Cavab verməzdən əvvəl yaxşı-yaxşı düşün.
> Is it going to rain? – I think so. = Yağış yağacaq? – Deyəsən, hə.
! THINK düzgün olmayan feldir: think – thought – thought (/θɔːt/). Fikir bildirmək mənasında davamedici zamanda işlənmir: "I think you are right" ("I am thinking you are right" səhvdir). Düşünmə prosesi üçün isə davamedici zaman mümkündür: I'm thinking about the problem. İnkar əsas feldə olur: I don't think he is at home. /θ/ səsi dilin ucu dişlərin arasında tələffüz olunur.

@ ENJOY | verb | ɪnˈdʒɔɪ | zövq almaq, həzz almaq, xoşlanmaq
forms: enjoy – enjoys – enjoyed – enjoyed – enjoying
n: enjoyment = zövq, həzz
adj: enjoyable = xoş, zövq verən
- enjoy yourself = əylənmək, vaxtını xoş keçirmək :: Qayıdış əvəzliyi ilə
- enjoy the view = mənzərədən zövq almaq :: view = mənzərə; həmçinin: baxış, fikir
- enjoy the sunshine = günəşli havadan həzz almaq :: sunshine = günəş işığı
- enjoy a concert = konsertdən zövq almaq :: concert = konsert
- enjoy dancing = rəqs etməyi sevmək :: enjoy + fel + -ing; dance = rəqs etmək
- enjoy nature = təbiətdən zövq almaq :: Artiklsiz: "the nature" deyilmir
- really enjoy = çox bəyənmək, əsl zövq almaq :: really = həqiqətən, çox
- enjoy singing = mahnı oxumağı sevmək :: sing – sang – sung
> Did you enjoy yourself at the party? = Qonaqlıqda yaxşı əyləndin?
> We sat on the balcony and enjoyed the view. = Biz eyvanda oturub mənzərədən zövq aldıq.
> I really enjoyed the film. = Film çox xoşuma gəldi.
> She enjoys dancing and singing. = O, rəqs etməyi və mahnı oxumağı sevir.
! ENJOY-dan sonra həmişə obyekt gəlməlidir: isim (enjoy the film), fel + -ING (enjoy dancing) və ya qayıdış əvəzliyi (enjoy yourself). "Enjoy to dance" səhvdir. Obyektsiz "I enjoyed" deyilmir – "I enjoyed it" və ya "I enjoyed myself" deyilir. Yemək verilərkən "Enjoy your meal!" deyilir. ENJOYABLE sifətdir: an enjoyable evening.

@ HOPE | verb, noun | həʊp | ümid etmək; ümid
forms: hope – hopes – hoped – hoped – hoping
adj: hopeful = ümidli; hopeless = ümidsiz, çarəsiz
adv: hopefully = ümid edirəm ki, inşallah
- I hope so = ümid edirəm ki, elədir :: Müsbət qısa cavab
- I hope not = ümid edirəm ki, yox :: "I don't hope so" deyilmir
- hope to hear from you = sizdən xəbər gözləyirəm :: Məktubun sonunda; hear = eşitmək
- hopes and dreams = ümidlər və arzular :: dream = arzu; həmçinin: yuxu
- in the hope of = nəyinsə ümidi ilə :: in the hope of + fel + -ing
- my only hope = yeganə ümidim :: only = yeganə; yalnız
- false hope = əsassız ümid, boş ümid :: false = yalan, saxta
- there is still hope = hələ ümid var :: still = hələ, hələ də
> Will she come? – I hope so. = O gələcək? – Ümid edirəm ki, hə.
> I hope to hear from you soon. = Tezliklə sizdən xəbər gözləyirəm.
> You are my only hope. = Sən mənim yeganə ümidimsən.
> Don't give up. There is still hope. = Təslim olma. Hələ ümid var.
! HOPE gələcəkdə mümkün olan bir şeyi arzulamaqdır. Qəliblər: hope + (that) + cümlə (I hope you are well), hope + to + fel (I hope to see you), hope for + isim. Gələcək məna üçün çox vaxt indiki zaman işlənir: I hope it doesn't rain tomorrow. HOPE real imkanı, WISH isə qeyri-real və ya çətin arzunu bildirir. Qısa cavablar: "I hope so" və "I hope not".

@ WORRY | verb, noun | ˈwʌri | narahat olmaq, nigaran qalmaq; narahatlıq, qayğı
forms: worry – worries – worried – worried – worrying
adj: worried = narahat, nigaran; worrying = narahatedici
- don't worry = narahat olma :: Ən çox işlənən təsəlli ifadəsi
- worry about = barəsində narahat olmaq :: worry about + isim / fel + -ing
- nothing to worry about = narahat olmağa dəyməz :: Təsəlli verərkən
- worry too much = həddindən artıq narahat olmaq :: too much = lazım olandan çox
- the main worry = əsas narahatlıq, başlıca qayğı :: main = əsas; burada "worry" isimdir
- slightly worried = bir qədər narahat :: slightly = azca, bir qədər
- terribly worried = olduqca narahat, çox nigaran :: terribly = dəhşətli dərəcədə (gücləndirici)
- worry about the kids = uşaqlara görə narahat olmaq :: kid = uşaq (danışıq dili)
> Don't worry. Everything will be fine. = Narahat olma. Hər şey yaxşı olacaq.
> My mother worries about me all the time. = Anam həmişə mənə görə narahat olur.
> It's nothing to worry about. = Narahat olmağa dəyməz.
> I'm slightly worried about the exam. = Mən imtahana görə bir qədər narahatam.
! WORRY fel kimi "narahat olmaq" deməkdir və ABOUT sözönüsü ilə işlənir: worry about money. WORRIED sifətdir və insanın halını bildirir (I am worried); WORRYING isə narahatlıq doğuran şey haqqında deyilir (worrying news). İsim kimi həm sayılan (my main worry), həm də sayılmayan ola bilər. Tələffüzə diqqət: /ˈwʌri/ – birinci sait "cup" sözündəki kimidir.
