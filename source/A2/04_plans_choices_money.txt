## Plans, choices and money | Planlar, seçimlər və pul
@ PLAN | noun, verb | plæn | plan; planlaşdırmaq
forms: plan – plans – planned – planned – planning
n: planning = planlaşdırma; planner = planlaşdırıcı, plan dəftəri
- plan a trip = səfər planlaşdırmaq :: trip = qısa səfər, gəzinti
- plan ahead = əvvəlcədən planlaşdırmaq :: ahead = qabaqcadan
- plan a wedding = toy planlaşdırmaq :: wedding = toy mərasimi
- plan a journey = səyahəti (yolu) planlaşdırmaq :: journey = bir yerdən digərinə uzun yol
- plan your future = gələcəyini planlaşdırmaq :: future = gələcək
- plan an event = tədbir planlaşdırmaq :: event = tədbir; hadisə
- plan a picnic = piknik planlaşdırmaq :: picnic = təbiət qoynunda yemək
- a study plan = dərs (hazırlıq) planı :: study = oxumaq, öyrənmək; təhsil
> We are planning a trip to Georgia. = Biz Gürcüstana səfər planlaşdırırıq.
> It is important to plan ahead. = Əvvəlcədən planlaşdırmaq vacibdir.
> I made a study plan for the exam. = Mən imtahan üçün dərs planı hazırladım.
> What are your plans for the weekend? = Həftə sonu üçün planların nədir?
! PLAN həm isim, həm də feldir. Fel kimi son samit qoşalaşır: planned, planning. Qəliblər: plan + isim (plan a trip), plan + to + fel (I plan to study abroad), plan for + isim. TRIP qısa səfərdir, JOURNEY isə bir yerdən digərinə gedilən yoldur. Gələcək niyyət üçün həm "I plan to ...", həm də "I'm planning to ..." işlənir.

@ CHOOSE | verb | tʃuːz | seçmək
forms: choose – chooses – chose – chosen – choosing
n: choice = seçim
- choose a career = peşə (karyera) seçmək :: career = peşə yolu, karyera
- choose between = arasında seçim etmək :: choose between A and B
- choose a university = universitet seçmək :: "a university": söz /j/ səsi ilə başlayır
- choose a course = kurs seçmək :: course = kurs; həmçinin: yemək növbəsi
- choose a topic = mövzu seçmək :: topic = inşa və ya təqdimat mövzusu
- choose an option = variant seçmək :: option = seçim variantı
- have no choice = başqa seçimi (çarəsi) olmamaq :: "choice" isimdir
- choose a design = dizayn seçmək :: design = dizayn, layihə
> It is not easy to choose a career. = Peşə seçmək asan deyil.
> I had to choose between the two jobs. = Mən iki iş arasında seçim etməli oldum.
> Choose a topic and write a short essay. = Bir mövzu seçin və qısa inşa yazın.
> We had no choice. We had to wait. = Bizim başqa çarəmiz yox idi. Gözləməli idik.
! CHOOSE düzgün olmayan feldir: choose /tʃuːz/ – chose /tʃəʊz/ – chosen. Yazılışa diqqət edin: indiki zamanda iki "o", keçmiş zamanda bir "o". CHOICE isimdir: make a choice – seçim etmək. Qəliblər: choose + isim, choose + to + fel (She chose to stay), choose between A and B, choose from + bir neçə variant.

@ PAY | verb, noun | peɪ | ödəmək, pul vermək; maaş
forms: pay – pays – paid – paid – paying
n: payment = ödəniş
adj: paid = ödənişli, haqqı ödənilən
- pay cash = nağd ödəmək :: "pay in cash" də deyilir
- pay attention = diqqət yetirmək, fikir vermək :: pay attention to + nə / kim
- pay in advance = əvvəlcədən ödəmək :: in advance = qabaqcadan
- pay tax = vergi ödəmək :: tax = vergi
- pay a fine = cərimə ödəmək :: Burada "fine" isimdir: cərimə
- pay back = (borcu) qaytarmaq :: Frazeoloji fel: pay the money back
- pay a fee = haqq (rüsum) ödəmək :: fee = xidmət və ya təhsil haqqı
- pay extra = əlavə pul ödəmək :: extra = əlavə
> Can I pay cash? = Nağd ödəyə bilərəm?
> Please pay attention to the teacher. = Zəhmət olmasa, müəllimə diqqət yetirin.
> You have to pay in advance. = Əvvəlcədən ödəməlisiniz.
> I'll pay you back tomorrow. = Sabah pulunu qaytaracağam.
! PAY düzgün olmayan feldir: pay – paid – paid (yazılışa diqqət: "payed" deyil). Qəliblər: pay + məbləğ və ya hesab (pay the bill); pay FOR + alınan şey (pay for the tickets); pay + şəxs (pay the driver). "Pay attention" sabit birləşmədir və pulla əlaqəsi yoxdur. İsim kimi PAY maaş deməkdir və sayılmayandır. FEE xidmət haqqı, FINE cərimə, TAX isə vergidir.

@ USE | verb, noun | juːz (verb), juːs (noun) | istifadə etmək, işlətmək; istifadə
forms: use – uses – used – used – using
n: user = istifadəçi
adj: useful = faydalı; useless = faydasız, yararsız
- use the internet = internetdən istifadə etmək :: Adətən "the" ilə
- use a dictionary = lüğətdən istifadə etmək :: dictionary = lüğət
- use a tool = alətdən istifadə etmək :: tool = alət
- use public transport = ictimai nəqliyyatdan istifadə etmək :: Sayılmayan isim: artiklsiz
- use a knife = bıçaq işlətmək :: knife /naɪf/ – "k" oxunmur; cəmi: knives
- use your brain = başını işlətmək, ağlını işə salmaq :: brain = beyin; danışıq dili
- use social media = sosial mediadan istifadə etmək :: social = ictimai, sosial
- use up = işlədib qurtarmaq, tükətmək :: Frazeoloji fel
> Do you use the internet every day? = Sən hər gün internetdən istifadə edirsən?
> You can use a dictionary in the exam. = İmtahanda lüğətdən istifadə edə bilərsiniz.
> I use public transport to get to work. = Mən işə getmək üçün ictimai nəqliyyatdan istifadə edirəm.
> We have used up all the milk. = Biz bütün südü işlədib qurtarmışıq.
! USE fel kimi /juːz/, isim kimi /juːs/ tələffüz olunur. Azərbaycan dilində "-dan istifadə etmək" deyilir, ingilis dilində isə sözönü lazım deyil: use a dictionary ("use from a dictionary" səhvdir). USEFUL – faydalı, USELESS – faydasız deməkdir. "Used to + fel" qəlibi ayrıdır və keçmişdəki vərdişi bildirir: I used to live in Ganja – Əvvəllər Gəncədə yaşayırdım.

@ PUT | verb | pʊt | qoymaq
forms: put – puts – put – put – putting
- put on = geyinmək, əyninə taxmaq :: Frazeoloji fel; əksi: take off
- put off = təxirə salmaq :: Frazeoloji fel: put off the meeting
- put away = yerinə yığmaq, yığışdırmaq :: Frazeoloji fel
- put out = (yanğını, siqareti) söndürmək :: Frazeoloji fel
- put up with = dözmək, tab gətirmək :: Üçsözlü frazeoloji fel; danışıq dili
- put the kettle on = çaydanı qoymaq (su qaynatmaq) :: Britaniya məişət ifadəsi
- put sth in the fridge = nəyisə soyuducuya qoymaq :: fridge = soyuducu (danışıq forması)
- put sth on the shelf = nəyisə rəfə qoymaq :: shelf = rəf; cəmi: shelves
> Put on your coat. It's cold outside. = Paltonu geyin. Bayırda soyuqdur.
> Don't put off your homework until tomorrow. = Ev tapşırığını sabaha saxlama.
> Please put your toys away. = Zəhmət olmasa, oyuncaqlarını yığışdır.
> I can't put up with this noise. = Mən bu səs-küyə dözə bilmirəm.
! PUT düzgün olmayan feldir və üç forması eynidir: put – put – put. PUT-dan sonra yer bildirilməlidir: put it ON the table, put it IN the fridge. Frazeoloji fellərdə məna tamamilə dəyişir: put on – geyinmək, put off – təxirə salmaq, put out – söndürmək, put up with – dözmək. "Put on" geyinmə hərəkətini, "wear" isə paltarın əynində olmasını bildirir.

@ STOP | verb, noun | stɒp | dayanmaq, dayandırmaq; dayanacaq
forms: stop – stops – stopped – stopped – stopping
adj: non-stop = fasiləsiz, dayanmadan
- stop talking = danışmağı dayandırmaq, susmaq :: stop + fel + -ing; talk = söhbət etmək
- stop smoking = siqareti tərgitmək :: smoke = siqaret çəkmək; tüstü
- stop crying = ağlamağı kəsmək :: cry = ağlamaq
- stop laughing = gülməyi kəsmək :: laugh /lɑːf/ = gülmək
- stop for a rest = dincəlmək üçün dayanmaq :: rest = istirahət, dincəlmə
- stop for petrol = benzin doldurmaq üçün dayanmaq :: Britaniyada "petrol", Amerikada "gas"
- a full stop = nöqtə (durğu işarəsi) :: Britaniya termini; full = dolu, tam
- stop shouting = qışqırmağı dayandırmaq :: shout = qışqırmaq
> Please stop talking and listen to me. = Zəhmət olmasa, danışmağı dayandırın və mənə qulaq asın.
> My father stopped smoking last year. = Atam keçən il siqareti tərgitdi.
> We stopped for a rest after two hours. = İki saatdan sonra dincəlmək üçün dayandıq.
> A sentence ends with a full stop. = Cümlə nöqtə ilə bitir.
! STOP-dan sonra gələn forma mənanı dəyişir: stop + fel + -ING = həmin işi görməyi dayandırmaq (He stopped smoking – siqareti tərgitdi); stop + TO + fel = başqa bir iş görmək üçün dayanmaq (He stopped to smoke – siqaret çəkmək üçün dayandı). Son samit qoşalaşır: stopped, stopping. İsim kimi STOP dayanacaqdır: a bus stop.

@ WIN | verb, noun | wɪn | qalib gəlmək, udmaq, qazanmaq; qələbə
forms: win – wins – won – won – winning
n: winner = qalib
- win a prize = mükafat (priz) qazanmaq :: prize = müsabiqədə verilən mükafat
- win a race = yarışda (qaçışda) qalib gəlmək :: race = sürət yarışı
- win a medal = medal qazanmaq :: a gold / silver / bronze medal
- win the lottery = lotereya udmaq :: Həmişə "the" ilə
- win an award = mükafata layiq görülmək :: award = rəsmi mükafat (film, kitab üçün)
- win the championship = çempionatın qalibi olmaq :: championship = çempionat
- win the final = finalda qalib gəlmək :: final = final oyunu
- win a contest = müsabiqədə qalib gəlmək :: contest = müsabiqə, yarışma
> She won first prize in the contest. = O, müsabiqədə birinci mükafatı qazandı.
> Who won the race? = Yarışda kim qalib gəldi?
> Our team won the final 3–0. = Komandamız finalda 3–0 hesabı ilə qalib gəldi.
> What would you do if you won the lottery? = Lotereya udsaydın, nə edərdin?
! WIN düzgün olmayan feldir: win – won – won (/wʌn/ – "one" sözü kimi tələffüz olunur). WIN oyun, yarış və ya mükafat ilə işlənir: win a match, win a prize. Rəqib haqqında isə BEAT işlənir: "We beat them" ("We won them" səhvdir). PRIZE yarışda qazanılan mükafat, AWARD isə nailiyyətə görə rəsmi verilən mükafatdır. Əksi: lose.
