## Learning and communication | Öyrənmə və ünsiyyət
@ LEARN | verb | lɜːn | öyrənmək
forms: learn – learns – learned / learnt – learning
n: learner = öyrənən (şəxs); learning = öyrənmə, təlim
- learn English = ingilis dilini öyrənmək :: Dil adları böyük hərflə yazılır
- learn a language = dil öyrənmək :: a foreign language = xarici dil
- learn to swim = üzməyi öyrənmək :: learn + to + fel
- learn to drive = maşın sürməyi öyrənmək :: drive = avtomobil sürmək
- learn words = sözləri öyrənmək :: Məsələn: learn ten new words a day
- learn by heart = əzbərləmək, əzbər öyrənmək :: İdiom; hərfi mənası "ürəklə"
- learn quickly = tez öyrənmək :: quick (cəld) + -ly
- learn about history = tarix haqqında öyrənmək :: learn about + mövzu
> I am learning English at school. = Mən məktəbdə ingilis dilini öyrənirəm.
> My sister is learning to drive. = Bacım maşın sürməyi öyrənir.
> Children learn languages quickly. = Uşaqlar dilləri tez öyrənirlər.
> We learned the poem by heart. = Biz şeiri əzbərlədik.
! LEARN bilik və ya bacarıq əldə etmək deməkdir; STUDY isə dərs oxumaq, bir fənni öyrənmək üçün çalışmaqdır. TEACH başqasına öyrətməkdir: The teacher teaches, the student learns. Britaniya ingiliscəsində keçmiş zaman həm "learned", həm də "learnt" ola bilər. Qəliblər: learn + to + fel (learn to swim), learn + about + mövzu (learn about history).

@ READ | verb | riːd | oxumaq (mətni)
forms: read /riːd/ – reads – read /red/ – read /red/ – reading
n: reader = oxucu; reading = oxu, mütaliə
- read a book = kitab oxumaq :: read a book about + mövzu
- read a story = hekayə oxumaq :: read sb a story = kiməsə hekayə oxumaq
- read a magazine = jurnal oxumaq :: magazine = jurnal ("mağaza" deyil!)
- read the news = xəbərləri oxumaq :: "news" sayılmayan isimdir: The news IS good
- read a letter = məktub oxumaq :: "letter" həm də "hərf" deməkdir
- read an email = elektron məktub oxumaq :: Sait səsdən əvvəl "an"
- read a map = xəritəni oxumaq :: Xəritədən istifadə etməyi bacarmaq
- read a text message = mətn mesajı (SMS) oxumaq :: Danışıqda qısaca: a text
> I read a book before I go to bed. = Mən yatmazdan əvvəl kitab oxuyuram.
> She read the letter twice. = O, məktubu iki dəfə oxudu.
> My father reads the news every morning. = Atam hər səhər xəbərləri oxuyur.
> Can you read this map? = Sən bu xəritəni oxuya bilirsən?
! READ düzgün olmayan feldir; yazılışı dəyişmir, lakin tələffüzü dəyişir: indiki zamanda /riːd/, keçmiş zamanda /red/. READ yalnız mətni oxumaq deməkdir. Universitetdə oxumaq (təhsil almaq) mənasında "study" işlənir, mahnı oxumaq isə "sing"dir – Azərbaycan dilindəki "oxumaq" felinin bu mənalarını qarışdırmayın.

@ WRITE | verb | raɪt | yazmaq
forms: write – writes – wrote – written – writing
n: writer = yazıçı; writing = yazı, yazı bacarığı
adj: written = yazılı
- write your name = adını yazmaq :: Blank doldurarkən: Write your name here
- write an address = ünvan yazmaq :: Yazılışa diqqət: address (iki "d", iki "s")
- write a sentence = cümlə yazmaq :: Dərs tapşırığı: Write a sentence with this word
- write a note = qeyd yazmaq; qısa məktub yazmaq :: note = qısa yazı
- write with a pen = qələmlə yazmaq :: Alət üçün "with"; pen = mürəkkəbli qələm
- write on the board = lövhədə yazmaq :: Səth üçün "on"
- write down = qeyd etmək, yazıb götürmək :: Frazeoloji fel: write it down
- write a postcard = açıqca yazmaq :: Səyahətdən göndərilən şəkilli kart
> Please write your name and address here. = Zəhmət olmasa, adınızı və ünvanınızı bura yazın.
> The teacher wrote a sentence on the board. = Müəllim lövhədə bir cümlə yazdı.
> Write down the new words in your notebook. = Yeni sözləri dəftərinizə yazın.
> She has written three books. = O, üç kitab yazıb.
! WRITE düzgün olmayan feldir: write – wrote – written. Sözün əvvəlindəki "w" tələffüz olunmur: /raɪt/. Qəliblər: write to + şəxs (write to me), write + şəxs + əşya (write me a letter). "Write down" bir şeyi unutmamaq üçün kağıza qeyd etmək deməkdir. WRITTEN sifət kimi "yazılı" mənasındadır: a written exam.

@ SPEAK | verb | spiːk | danışmaq
forms: speak – speaks – spoke – spoken – speaking
n: speaker = danışan (şəxs), natiq, həmçinin səsucaldan; speech = nitq, çıxış
adj: spoken = şifahi, danışıq
- speak Azerbaijani = Azərbaycan dilində danışmaq :: Dil adı ilə sözönü işlənmir
- speak slowly = yavaş danışmaq :: slow (yavaş) + -ly
- speak loudly = uca səslə danışmaq :: loud (uca) + -ly
- speak clearly = aydın danışmaq :: clear (aydın) + -ly
- speak politely = nəzakətlə danışmaq :: polite (nəzakətli) + -ly
- speak up = (eşidilmək üçün) bir az ucadan danışmaq :: Frazeoloji fel: Speak up, please
- speak to sb = kiminləsə danışmaq :: Britaniyada "speak to", Amerikada daha çox "speak with"
- a native speaker = dil daşıyıcısı (həmin dil ana dili olan şəxs) :: a native speaker of English
> Do you speak Azerbaijani? = Siz Azərbaycan dilində danışırsınız?
> Could you speak slowly, please? = Zəhmət olmasa, yavaş danışa bilərsinizmi?
> Can I speak to Mr Brown, please? = Zəhmət olmasa, cənab Braunla danışa bilərəm?
> Our teacher is a native speaker of English. = Müəllimimiz ingilis dilinin daşıyıcısıdır.
! SPEAK dil bilmək və ümumiyyətlə danışmaq qabiliyyəti üçün işlənir (speak English), TALK isə daha çox söhbət etmək mənasındadır. Düzgün olmayan feldir: speak – spoke – spoken. Zərflər sifətə -ly artırmaqla düzəlir: slow → slowly, clear → clearly, polite → politely. "Speak to" telefonda və rəsmi müraciətdə çox işlənir.

@ ASK | verb | ɑːsk | soruşmaq; xahiş etmək
forms: ask – asks – asked – asked – asking
- ask a question = sual vermək :: "give a question" deyilmir
- ask the way = yolu soruşmaq :: ask sb the way to + yer
- ask for the bill = hesabı istəmək :: Restoranda: Can we have the bill, please?
- ask about the price = qiyməti soruşmaq :: ask about + nə barədə
- ask for information = məlumat istəmək :: Sayılmayan isim: "informations" deyilmir
- ask again = yenidən soruşmaq :: again = yenə, bir də
- ask sb to wait = kimdənsə gözləməyi xahiş etmək :: ask + şəxs + to + fel
- ask for the menu = menyunu istəmək :: ask for = istəmək, xahiş etmək
> Can I ask a question? = Sual verə bilərəm?
> We asked a man the way to the station. = Biz bir kişidən vağzala gedən yolu soruşduq.
> Let's ask for the bill. = Gəl, hesabı istəyək.
> She asked me to wait outside. = O məndən bayırda gözləməyi xahiş etdi.
! ASK-ın iki əsas mənası var: 1) soruşmaq – ask a question, ask about + mövzu; 2) xahiş etmək, istəmək – ask for + əşya, ask + şəxs + to + fel. Şəxs sözönüsüz gəlir: "ask me" ("ask to me" səhvdir). Azərbaycanca "sual vermək" deyilir, ingiliscə isə "ask a question". Britaniya tələffüzü uzun saitlədir: /ɑːsk/.

@ LISTEN | verb | ˈlɪsən | qulaq asmaq, dinləmək
forms: listen – listens – listened – listened – listening
n: listener = dinləyici; listening = dinləmə (dil bacarığı)
- listen to music = musiqiyə qulaq asmaq :: "to" mütləqdir: "listen music" səhvdir
- listen to the radio = radioya qulaq asmaq :: "the" artikli ilə işlənir
- listen to a song = mahnıya qulaq asmaq :: song = mahnı
- listen carefully = diqqətlə qulaq asmaq :: careful (diqqətli) + -ly
- listen and repeat = qulaq as və təkrar et :: Dərslik tapşırığı
- listen to a podcast = podkasta qulaq asmaq :: Dil öyrənmək üçün faydalı vərdiş
- listen to the birds = quşlara (quşların səsinə) qulaq asmaq :: Təbiət haqqında danışarkən
- listen to a conversation = söhbətə qulaq asmaq :: İmtahanın dinləmə hissəsində
> I listen to music on the bus. = Mən avtobusda musiqiyə qulaq asıram.
> Listen carefully and repeat the words. = Diqqətlə qulaq asın və sözləri təkrar edin.
> My father listens to the radio in the car. = Atam maşında radioya qulaq asır.
> Listen! Can you hear the birds? = Qulaq as! Quşları eşidirsən?
! LISTEN diqqətlə, qəsdən qulaq asmaq deməkdir və obyektdən əvvəl həmişə "to" tələb edir: listen TO music. HEAR isə səsi eşitmək (istəmədən də) deməkdir: I can hear a noise. Sözdəki "t" hərfi tələffüz olunmur: /ˈlɪsən/. Diqqəti cəlb etmək üçün "Listen!" təkbaşına işlənir.
